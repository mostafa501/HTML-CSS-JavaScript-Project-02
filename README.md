# HTML-CSS-JAVASCRIPT-PROJECT-02

A responsive and interactive one-page website developed using **HTML5**, **CSS3**, and **JavaScript** as part of my new web development projects.

## Project Overview

This project is a front-end website created to practice and apply HTML, CSS, and JavaScript concepts. It focuses on building a structured, responsive, and interactive website by combining HTML for content structure, CSS for styling and layouts, and JavaScript for dynamic functionality and user interactions.

The design is based on the [Kasper One Page PSD Template](https://www.graphberry.com/item/kasper-one-page-psd-template#google_vignette) by Graphberry — a free PSD template featuring a modern design and clean visual layout.

## Technologies Used

* **HTML5** – Website structure and content.
* **CSS3** – Styling, layouts, and responsive design.
* **JavaScript (ES6+)** – DOM manipulation and interactive functionality.
* **Font Awesome** – Icons.
* **Google Fonts (Open Sans)** – Typography.
